# default-design

Ein generisches Design-Skill als Platzhalter. Ersetze diesen Folder durch deine echten Brand Guidelines (z.B. als ZIP-Export aus claude.ai/design).

## Brand Tokens

```
bg: #0A0A0A
ink: #F5F5F5
accent: #6366F1
accent-dim: #4338CA
muted: #3F3F46
font-display: DM Sans
font-data: JetBrains Mono
```

## Stil

Modern, clean, minimalistisch. Klare Hierarchien. Kein Noise.

## Verwendung

Dieses Skill wird von Claude geladen wenn keine spezifische Brand genannt wird. Für eigene Brands: `brand-guidelines/<name>/SKILL.md` anlegen und beim Edit-Prompt angeben.
