# Brand Colors — Default

Ersetze diese Platzhalter durch deine eigenen Farben.

| Token | Hex | Verwendung |
|---|---|---|
| `--bg` | `#0A0A0A` | Hintergrund |
| `--ink` | `#F5F5F5` | Primärtext |
| `--accent` | `#6366F1` | Highlights, CTAs |
| `--accent-dim` | `#4338CA` | Hover-States, Sekundär-Akzente |
| `--muted` | `#3F3F46` | Sekundärtext, Borders |

```css
:root {
  --bg: #0A0A0A;
  --ink: #F5F5F5;
  --accent: #6366F1;
  --accent-dim: #4338CA;
  --muted: #3F3F46;
}
```
