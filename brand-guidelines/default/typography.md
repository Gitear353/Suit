# Brand Typography — Default

Ersetze diese Platzhalter durch deine eigenen Fonts.

## Display Font

**DM Sans** — für Headlines, Overlays, große Zahlen
- Google Fonts: https://fonts.google.com/specimen/DM+Sans
- Weights: 400, 500, 700

## Data / Body Font

**JetBrains Mono** — für Daten, Code, kleine Labels
- Google Fonts: https://fonts.google.com/specimen/JetBrains+Mono
- Weights: 400, 700

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;700&family=JetBrains+Mono:wght@400;700&display=swap" rel="stylesheet">
```

```css
--font-display: 'DM Sans', sans-serif;
--font-data: 'JetBrains Mono', monospace;
```
